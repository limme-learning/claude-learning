# UI & UX Impeccable Craft Rules

## Quality Floor & Standards
- Contrast ratio $\ge 4.5:1$ (WCAG AA) across Light & Dark themes.
- Genuine elevation with soft blur and offset (`box-shadow: 0 4px 20px -2px rgba(0,0,0,0.06)`).
- Complete state matrix: `:hover`, `:focus-visible:ring-2`, `:active:scale-[0.98]`, `:disabled`, skeleton loaders.
- Anti-patterns strictly banned:
  - 🚫 No nested cards inside cards.
  - 🚫 No eyebrow/kicker uppercase tags above headers.
  - 🚫 No gradient text fills.
  - 🚫 No unstyled empty states.
