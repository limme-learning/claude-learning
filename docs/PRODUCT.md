## Platform

web

## Overview

UI Kit is a modern, headless dual-engine component library and showcase application supporting both `@base-ui/react` and `@radix-ui/*` primitives with unified styling powered by the shadcn design system and Tailwind CSS v4.

## Target Audience

Designers, frontend engineers, and developers building accessible, production-grade web applications with high visual craft and full keyboard/screen-reader navigation.

## Core Capabilities

- **Dual-Engine Headless Architecture**: Complete symmetry between Base UI and Radix UI primitives.
- **Unified Design Tokens**: Full OKLCH color scale with dark mode parity and multiple style namespaces.
- **Enterprise-Grade Blocks**: Complex data grids, Gantt charts, date range pickers, tree views, and command palettes.
- **Accessible & Responsive**: WCAG AA compliance, full interaction state coverage, and mobile-adaptive layout.
